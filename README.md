# clean-v-

איפוס אוטומטי של עמודת "הגשת משמרות" (עמודה B) בגיליון **פורמט סידור עבודה**, לשונית **פורמט**.

כל מוצ"ש ב-**23:59 שעון ישראל** כל תא בעמודה B שערכו `v` מוחלף אוטומטית ל-`---`
(ברירת המחדל השחורה של הרשימה הנפתחת). שאר הערכים — `חופש`, `מילואים`, `לא כשיר`, `קליטה` — לא נגעים.

> אין דרך לעשות את זה עם נוסחה או עם עיצוב מותנה: נוסחה לא יכולה לדרוס ערך שהוזן ידנית בתא,
> ועיצוב מותנה רק צובע ולא משנה את הערך, וגם לא רץ לפי שעון. Apps Script הוא הפתרון היחיד.

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `apps-script/Code.gs` | כל הקוד: האיפוס עצמו + התזמון |
| `apps-script/appsscript.json` | הגדרות הפרויקט, כולל אזור זמן ירושלים |

## התקנה — שלב אחר שלב

1. פותחים את הגיליון:
   https://docs.google.com/spreadsheets/d/1Te8nEh6CmR1B6uXwA4DTxZUljHEZH4NrKkMCHV_PI_I/edit
2. בתפריט העליון: **תוספים** (Extensions) ← **Apps Script**. נפתחת לשונית חדשה בדפדפן.
3. במסך שנפתח, בצד שמאל, לוחצים על הקובץ **`Code.gs`** (או `קוד.gs`).
   מוחקים את כל מה שכתוב בו (Ctrl+A ואז Delete) ומדביקים במקומו את כל התוכן של
   [`apps-script/Code.gs`](apps-script/Code.gs) מהריפו הזה.
4. מגדירים אזור זמן:
   - בצד שמאל לוחצים על סמל גלגל השיניים **⚙ הגדרות פרויקט** (Project Settings).
   - מסמנים ✅ **"הצג את קובץ המניפסט `appsscript.json` בעורך"**
     (Show "appsscript.json" manifest file in editor).
   - חוזרים ל-**עורך** (`< >` בצד שמאל), לוחצים על הקובץ **`appsscript.json`** שהופיע,
     ומוודאים שהשורה הראשונה היא:
     ```json
     "timeZone": "Asia/Jerusalem",
     ```
     אם לא — מתקנים לזה ושומרים.
5. שומרים: **Ctrl+S** (או סמל הדיסקט 💾).
6. מריצים את ההתקנה:
   - בסרגל העליון של העורך, בתיבת הבחירה שליד כפתור **הרצה** (Run), בוחרים את הפונקציה **`setup`**.
   - לוחצים **הרצה** (Run).
   - נפתח חלון הרשאות: **בדיקת הרשאות** ← בוחרים את חשבון Google שלכם ←
     אם מופיע "Google לא אימתה את האפליקציה" לוחצים על **מתקדם** (Advanced) ←
     **מעבר אל ...(לא בטוח)** ← ואז **אישור** (Allow).
   - בתחתית המסך נפתח יומן ביצוע (Execution log) שאמור להסתיים ב-
     `הותקן. ההרצה הבאה: Sat ... 23:59:00`.

זהו. מעכשיו זה רץ לבד כל שבוע.

## איפה רואים את יומן הביצוע

אחרי כל לחיצה על **הרצה** (Run) בעורך, נפתח בתחתית המסך חלון **יומן הביצוע** (Execution log)
עם כל מה שהפונקציה כתבה. אם סגרת אותו: **תצוגה** (View) ← **יומנים** (Logs), או Ctrl+Enter.

מסך ה-**ביצועים** (Executions, סמל ה-▶ בצד שמאל) מציג רק *שהריצה קרתה* ואת הסטטוס שלה.
אם כתוב שם `No logs are available for this execution` זה בדרך כלל אומר שהפונקציה פשוט
לא כתבה כלום ליומן — לא שמשהו נכשל. סטטוס **Completed** = הריצה הצליחה.

## איך מוודאים שזה עובד

- **בדיקה מיידית:** בוחרים בתיבת הפונקציות את **`resetGreenV`** ולוחצים **הרצה**.
  כל ה-`v` שקיימים כרגע בעמודה B יהפכו ל-`---`. (אחרי זה אפשר לבטל עם Ctrl+Z בגיליון.)
- **בדיקת מצב כללית:** בוחרים את הפונקציה **`checkStatus`** ולוחצים **הרצה**. היומן יראה
  לאיזה קובץ הסקריפט מחובר, מה אזור הזמן, האם יש טריגר פעיל, וכמה תאי `v` יש כרגע בעמודה B.
- **בדיקת התזמון:** בצד שמאל בעורך לוחצים על סמל השעון ⏰ **טריגרים** (Triggers).
  אמור להופיע שם טריגר אחד לפונקציה `weeklyReset` מסוג *לפי שעה/תאריך*.
- **אחרי ההתקנה, ברענון הבא של הגיליון** יופיע בתפריט העליון תפריט חדש בשם **איפוס משמרות**
  עם שלוש אפשרויות: איפוס עכשיו, הפעלה/רענון של התזמון, וביטול התזמון.

## למה טריגר חד-פעמי שמחדש את עצמו

הטריגר השבועי הרגיל שמגדירים דרך מסך ה-Triggers תומך רק ב**טווח שעות** ("23:00 עד חצות"),
ולא בדקה מדויקת. לכן הקוד כאן יוצר בכל פעם טריגר **לרגע מסוים** (מוצ"ש הקרוב 23:59),
והפונקציה `weeklyReset` קובעת מיד בסיומה את המועד של השבוע הבא. כך גם מקבלים 23:59 מדויק
וגם המעבר בין שעון חורף לשעון קיץ מטופל לבד.

הערה כנה אחת: גוגל לא מתחייבת לשנייה מדויקת — בפועל ההרצה קורית בדרך כלל תוך דקה-שתיים מהזמן
שנקבע, ולפעמים מתעכבת יותר בעומס. לכן אם חשוב שהאיפוס ייגמר **לפני** חצות, אפשר לשנות בקובץ
`Code.gs` את השורה `var RUN_MINUTE = 59;` ל-`var RUN_MINUTE = 50;` ולהריץ שוב את `setup`.

## שינוי הגדרות

כל מה שסביר שתרצו לשנות נמצא בראש `Code.gs`:

```js
var SHEET_NAME   = 'פורמט';  // שם הלשונית
var COLUMN       = 2;         // עמודה B
var FIRST_ROW    = 2;         // שורת הנתונים הראשונה
var VALUE_FROM   = 'v';       // הערך שמתאפס
var VALUE_TO     = '---';     // הערך שאליו מאפסים
var RUN_WEEKDAY  = 6;         // 0=ראשון ... 6=שבת
var RUN_HOUR     = 23;
var RUN_MINUTE   = 59;
```

אחרי כל שינוי: שומרים (Ctrl+S) ומריצים שוב את **`setup`**.

## ביטול האוטומציה

מריצים את הפונקציה **`removeTriggers`**, או משתמשים בתפריט **איפוס משמרות ← בטל תזמון שבועי**.
